# Dataset SHL (Sussex-Huawei Locomotion)

Esta carpeta incluye lo siguiente: 
- Modelos: model_SHL.pkl (completo) y model_SHL_Hand.pkl (solo para valores de móvil en la mano)
- Label_enconder: Para poder testear el modelo con otros datos.
- Notebooks desarrollado para estudiar el dataset.

Scripts:
- Txt to CSV.py: Sirve para transformar cada fichero con formato <position>_Motion.txt a formato CSV.
- Label to CSV.py: Creado para transformar los ficheros Label.txt a formato CSV.
